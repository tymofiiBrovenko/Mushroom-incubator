# Mushroom Incubator (ESP32s) - In work

<img width="2351" height="1764" alt="IMG_20261008_213803779" src="https://github.com/user-attachments/assets/240a7666-1a35-4820-965d-0ee451f92174" />


This project is an automated, low-cost microclimate control system inside a 65L plastic box, or simply a mushroom incubator. I built it mainly as tiny greenhouse for my parents. It runs on a ESP32s and is coded on Arduino.

## Key Features

* **Humidity control** - reads data from an SHT31 sensor what triggers an ultrasonic mist maker(goal-humidity - 85%).
* **Timed Ventilation** cycled CO2 removal.
* **Automatic Lighting** 12-hour ON/OFF daily light cycle
